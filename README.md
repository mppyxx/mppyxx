### Building now

**[Claude Power Pack](https://github.com/mppyxx/claude-power-pack)** · open source  
The complete Claude Code setup in one folder: 94 skills, 9 plugins, working rules and a guide to 14 connectors. Open it in Claude Code, type `install this`, and it backs up your current setup before it changes anything. It updates itself without touching your own edits. [Website](https://mppyxx.github.io/claude-power-pack/)

**Leo** · early access  
The AI assistant I built for myself, now opening up to other people. Leo lives in your Instagram DMs. Send him a reel you were going to save and never open, and he does the work, whether that's a new Claude Code skill or a straight answer that the reel is hype. He answers voice notes in English, Hindi and Gujarati, takes video calls, and has his own Mac and iPhone apps. Built with Claude Code, Cloudflare Workers and Swift. For early access, DM "leo" to [@leo.assist](https://www.instagram.com/leo.assist/).
